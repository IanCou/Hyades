# Docs site

The Docusaurus site you're reading. Local-only: no public Cloudflare tunnel route.
Added 2026-04-17 ([changelog](../changelog/2026-04-17.md)).

Deployed with `ansible-playbook playbooks/docs.yml`, not the standard `deploy.yml`.

Source: [docusaurus/](https://github.com/IanCou/Hyades/tree/main/docusaurus) · IP/LXC/route: [network.md](../network.md)

## Request path

```
Mac on Tailscale
  → AdGuard (10.0.1.16)       *.example.com → 10.0.1.10
  → Caddy (10.0.1.10)         docs.iancoutinho.net block
  → nginx on docs LXC (:80)       serves prebuilt static site
```

(MagicDNS is deliberately disabled; see [AdGuard](./adguard.md) and
[Tailscale](./tailscale.md) for how DNS is actually pinned.)

## Layout

A single docs instance (`docusaurus/docs/`, served at `/docs/`) with an autogenerated
sidebar (`sidebars.js`); `index.md` uses `slug: /` to land at the root. Config lives in
`docusaurus/docusaurus.config.js`.

## Build & deploy

- Multi-stage `Dockerfile` (`node:22-alpine` builder → `nginx:alpine`); only static
  output ships, no Node at runtime.
- The build happens **on the target LXC** via `docker compose up --build`; peak RAM is
  ~1.5GB.
- `docs.yml` rsyncs the source tree with
  [`ansible.posix.synchronize`](https://docs.ansible.com/ansible/latest/collections/ansible/posix/synchronize_module.html)
  (excluding `node_modules`, `build`, `.docusaurus`, `.git`), then runs
  `docker_compose_v2` with `build: always`.
- The TLS cert comes from Caddy's DNS-01 challenge, so the subdomain just needs to exist
  in the Cloudflare zone, no HTTP reachability required.

## CI/CD

`.github/workflows/ci.yml`'s `deploy` job detects changes under `docusaurus/**` and runs
`ansible-playbook playbooks/docs.yml`. Services under `services/**` still route through
`playbooks/deploy.yml`.
